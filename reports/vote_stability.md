# 판정 흔들림과 3회 다수결 (2026-11-03)

v1.1 Sonnet을 파일럿 60문항에 6회 실행(기존 2회 + 추가 4회). 칸 = 문항×축 360칸. 정답은 수정 정답(18칸 반영).
코드: `bridgecore/vote.py` (칸별 다수결 병합, 적응형 3회, 일치도 측정)

## 1. 실제로 얼마나 흔들리나
- 6회 모두 같은 판정인 칸: **340/360 (94%)**. 흔들리는 칸은 20개뿐
- 훼손 표 수 분포: 0/6 301칸, 6/6 39칸, 1/6·5/6 7칸, 2~4/6 13칸
- 실행 2개끼리 훼손 여부 κ 평균 0.88 (0.83~0.91), 평균 9.7칸 다름
- 축 단위 F1 (전체 60문항): 평균 0.768, 범위 0.73~0.79, 표준편차 0.021. 개발용 40문항만 보면 0.74~0.81 (문항이 적을수록 커 보임)

## 2. 3회 다수결은 효과가 거의 없음
| | 단일 실행 | 3회 다수결 |
|---|---|---|
| 서로 다른 실행(묶음)끼리 κ | 0.880 | 0.881 |
| 서로 다른 실행(묶음)끼리 다른 칸 수 | 9.7 | 9.4 |
| 축 단위 F1 평균 (범위) | 0.768 (0.73~0.79) | 0.773 (0.74~0.80) |
| 호출 수 / 문항 | 1 | 2.27 (적응형) |

흔들리는 칸 대부분이 2~4/6처럼 반반에 가까워서, 세 번 투표해도 결과가 동전 던지기처럼 갈린다. **비용 2.3배에 이득 없음 → 채택 안 함**

## 3. 대신 흔들림이 '확신도' 신호가 됨
| 칸 종류 | 칸 수 | 다수 판정이 정답과 일치 |
|---|---|---|
| 6회 모두 같음 | 340 | 0.96 |
| 1/6·5/6 | 7 | 0.71 |
| 2~4/6 | 13 | 0.58 |

- 6회 모두 훼손인 칸의 정밀도 0.92, 흔들리는 칸(1~5/6)을 훼손으로 보면 정밀도 0.20
- 두 번 돌려 **두 번 다 훼손일 때만 표시**: 정밀도 0.81→0.87, 재현율 0.74→0.72, F1 0.768→0.786 (비용 2배)
- 리포트 활용안: 1회 실행 후 훼손이 나온 문항만 한 번 더 돌려(파일럿 기준 약 절반) 두 번 다 훼손이면 '확실', 한 번만이면 '검토 필요'로 표시 → 비용 약 1.5배

## 결론
- 운영: 단일 실행 유지. 확신도 표시가 필요하면 위 활용안
- 최종 평가: 각 구성을 3회 실행해 평균과 범위를 보고 (운 좋은 실행 하나로 결론 내지 않기)
- 한계: 60문항·Sonnet만 측정. 확신도와 정답 일치의 관계는 칸 20개로 본 것이라 본검수에서 다시 확인 필요

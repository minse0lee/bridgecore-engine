## 3. 호칭 (지침 6번에 더할 것)

- 원문에 Miss, Mr., Mrs.가 없으면 "양", "씨", "부인"을 붙이지 않는다. 이름만 있으면 이름만 쓴다.
- 데이지는 기혼이므로 "데이지 양"이라고 하지 않는다.
- 닉과 데이지의 관계: second cousin once removed는 "먼 친척", 이후의 cousin은 "친척"으로 옮긴다(현재: 사촌 · 재종질녀뻘이 섞임).
- 캐서린은 머틀의 "동생"으로 옮긴다(현재: 동생 · 언니가 섞임. 원문은 sister이고, 캐서린 서른쯤 · 머틀 서른 중반이라는 나이에서 미룬 것).

## 4. 말투 임시안 (지침 4번에 더할 것)

| 누가 → 누구에게 | 임시안 | 현재 번역 |
|---|---|---|
| 개츠비 → 모든 상대 | 격식 있는 존댓말(-습니다, -요) | 존댓말이 다수, 반말·하게체가 섞임 |
| 닉 → 개츠비, 조던 | 존댓말(-요) | 대체로 -요 |
| 조던 → 닉 | 존댓말(-요) | 대부분 -요, 일부 반말 |
| 닉 ↔ 데이지 | 서로 -요체 | 데이지→닉은 -요가 다수, 일부 반말 |
| 닉 ↔ 톰 | 서로 반말 | 섞임 |
| 톰 ↔ 데이지 | 서로 반말 | "톰 씨"와 높임이 섞임 |
| 톰 → 윌슨, 머틀 | 반말 | 높임이 섞임 |
| 윌슨 → 톰 | 존댓말 | 존댓말 |
| 톰 ↔ 개츠비 | 톰은 반말, 개츠비는 존댓말 | 섞임 |
| 집사·하인 → 주인과 손님 | 존댓말(-습니다) | 대체로 존댓말 |

## 5. 시험 계획(안)

- 대상: 1·3장 전체(638문장) + 7장 303문장. 같은 문장을 조건별로 다시 번역한다.
- 조건 ① 지침에 2~4장을 더함. 조건 ② ① + 뒤 문단 원문도 문맥으로 줌.
- 볼 것: 2장 표의 표기 불일치 수(코드로 셈), "양"·"씨" 덧붙임 수(코드로 셈), 개츠비 대사의 존댓말 비율(코드로 셈), 엔진 지적 수("앞 5 + 뒤 5문장" 설정, 오늘의 A 실행과 비교).

# 개츠비 1·3장 재번역 시험 (2026-11-27)

대상: 학습 전 Gemma 4 31B(ctx5) 번역 중 검증엔진 v1.1이 훼손으로 짚은 150문장(minor 142, major 8).
방법: 짚인 문장만 같은 모델로 다시 번역(bf16, greedy, 생각 끔, L20 2장). 조건 둘 — reason(엔진의 오류 설명·판정 이유 제공), plain(이유 없이 "다시 대조해 문제 있으면 고쳐라"). 두 조건 모두 "그대로 두기" 허용.
판정: 같은 엔진 v1.1(Sonnet 5.5, effort medium)로 재검증. 대조(control) = 번역을 바꾸지 않고 같은 150문장을 다시 판정.

기타
- reason: 번역이 바뀐 문장 150/150. 남은 훼손 30문장 중 처음과 같은 축이 남은 것 27, 처음에 없던 축이 새로 짚인 것 6. 새 major 1.
- plain: 번역이 바뀐 문장 133, 그대로 17. 남은 훼손 74문장 중 같은 축 73, 새 축 11.
- 형식: 모델 답에서 닫는 따옴표가 빠져 저장되지 않은 문장 reason 2, plain 3 → raw 기록의 greedy 출력에서 복구(표시 남김). 엔진 형식오류 각 1문장.

한계
- 재검증을 같은 엔진이 했다. 엔진이 적은 이유대로 고치면 그 엔진의 판정이 풀리는 것은 어느 정도 당연하며, 사람이 보기에 번역이 나아졌는지는 별도 확인이 필요하다. 자연스러움은 이 엔진이 직접 재지 않는다.
- 엔진 판정 자체가 흔들린다: 번역을 바꾸지 않아도 16%가 훼손 없음으로 바뀌었다.
- 짚이지 않은 문장은 다시 보지 않았다(같은 문단의 문맥이 조금 바뀜).
- 두 장 150문장.
